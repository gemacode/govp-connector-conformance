# GOVP Connector Conformance

Runner independiente del contrato `org.govp.exchange/1`. Verifica identidad,
emisión nueva, replay idempotente, comprobación pública y publicación de la
revocación. Todos los sujetos que crea están marcados como ficticios y la prueba
termina revocando su GOVP.

Un informe positivo significa **conforme con el contrato técnico probado**. No
es una certificación legal, comercial ni una prueba nativa del ERP.

```bash
npm install github:gemacode/govp-connector-conformance#v0.1.0
```

Código y releases: <https://github.com/gemacode/govp-connector-conformance>.
